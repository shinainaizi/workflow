# 社区活动台账自动化工作流

> **AI驱动的活动策划复盘系统**：自动从策划方案 + 现场记录 → 生成标准化台账 → 汇总分析报告

## 项目背景

在社区活动策划实习中，我发现每次活动结束后需要手动撰写台账，内容重复性高、格式固定，却需要花费30-60分钟。这个项目通过AI自动化，将这一过程压缩到5分钟，同时生成可用于复盘优化的汇总报告。

## 核心流程

```
活动策划方案(.docx) 
        +
现场照片 + 回忆记录(.txt)
        ↓
[信息提取模块]
        ↓
[台账生成模块] ──→ 活动台账(.docx)
        ↓
[汇总报告模块] ──→ 月度/季度汇总报告(.docx)
```

## 项目亮点

| 特性 | 说明 |
|------|------|
| **端到端自动化** | 从Word方案输入到Word台账输出，全程无需手动填写 |
| **双模式架构** | 演示模式（零成本规则引擎）+ AI模式（大模型智能增强） |
| **非结构化输入兼容** | 支持口语化回忆记录、现场照片，无需固定表格 |
| **模块化设计** | 信息提取、台账生成、报告生成三个独立模块，易于扩展 |
| **降级策略** | API不可用时自动切换本地规则引擎，确保可用性 |

## 技术栈

- **Python 3.8+** —— 核心开发语言
- **百度千帆API** —— ERNIE-Speed（免费）/ ERNIE-4.0-Turbo-VL（多模态）
- **python-docx** —— Word文档读取与生成
- **正则表达式 + 规则引擎** —— 结构化信息提取（演示模式）

## 快速开始

### 演示模式（无需API Key）

```bash
# 1. 克隆仓库
git clone https://github.com/shinainaizi/workflow.git
cd workflow

# 2. 安装依赖（仅需python-docx）
pip install python-docx

# 3. 运行演示
python demo_run.py

# 4. 查看输出
# outputs/ledger/   → 生成的台账
# outputs/report/   → 生成的汇总报告
```

### 生产模式（接入AI）

```bash
# 1. 注册百度千帆获取API Key（免费额度）
# https://console.bce.baidu.com/qianfan/

# 2. 编辑 config.yaml，填入API Key，设置 demo_mode: false

# 3. 安装完整依赖
pip install -r requirements.txt

# 4. 运行完整流程
python run.py --scheme "活动方案.docx" --photos "照片文件夹" --notes "回忆记录.txt"
```

## 项目结构

```
workflow/
├── README.md                  # 项目说明
├── requirements.txt           # Python依赖
├── config.yaml               # 配置文件（API Key、模型选择）
├── run.py                    # 生产入口（需API Key）
├── demo_run.py               # 演示入口（零成本）
├── core/                     # 核心模块
│   ├── llm_client.py        # 大模型API封装
│   ├── extract.py           # 信息提取（方案+照片+回忆）
│   ├── generate_ledger.py   # 台账生成（Word表格）
│   └── generate_report.py   # 报告生成（汇总分析）
├── examples/                 # 示例数据
│   ├── scheme.docx           # 活动策划方案样本
│   ├── 回忆记录.txt            # 回忆记录样本
│   └── reference_ledger.docx # 参考台账输出
└── outputs/                  # 运行产出（自动生成，.gitignore已排除）
    ├── ledger/              # 活动台账
    └── report/              # 汇总报告
```

## 输入输出示例

### 输入：活动策划方案（节选）

```
活动主题：感统小乐园·超市购物员
活动时间：6月25日 10:45-11:15
活动地点：申沁社区大运河幸福家园
参与对象：15组亲子家庭（22个月-36个月）

活动目的：
丰富婴幼儿成长驿站感统趣味活动内容，依托模拟超市场景
开展职业角色扮演，锻炼幼儿肢体协调、手部精细动作、触觉感知等感统能力。

活动流程：
环节一：超市小课堂·感统认知科普（3分钟）
环节二：岗位示范·感统动作教学（8分钟）
环节三：亲子角色扮演·超市实操（8分钟）
环节四：货架整理·协作感统挑战（8分钟）
```

### 输入：回忆记录（口语化）

```
实际到场16组家庭，比预期多了1组
宝宝最喜欢仿真收银台，排队抢着玩
有个老奶奶说"从来没见过这么有意思的活动"
问题：准备的钱币不够，购物车只有5个，音响声音小
建议：下次多准备道具，提前测试设备，严格控制时间
```

### 输出：自动生成的台账

| 时间 | 2026.6.25 10:45-11:15 |
|------|----------------------|
| 活动主题 | 感统小乐园·超市购物员 |
| 参加人员 | 15组亲子家庭 |
| 活动内容 | 6月25日上午10:45，申沁社区婴幼儿成长驿站开展「感统小乐园·超市购物员」公益感统训练活动，吸引16组22-36月龄宝宝及家长到场参与。本次活动以听觉记忆训练与角色扮演游戏为载体，依次开展规则讲解、示范引导、亲子闯关、互动分享等环节... |
| 备注 | 预期参与: 15组 实际参与: 16组家庭 / 亮点: 宝宝最喜欢仿真收银台... / 问题: 准备的钱币不够... / 改进: 下次多准备道具... |

### 输出：自动生成的汇总报告（结构）

- **一、总体概况**：本周期内共举办社区活动X场，累计参与人数约XX人次
- **二、活动统计**：活动分类、参与人数统计（最多/最少/平均）
- **三、活动详情**：每场活动的时间、地点、参与人数、内容摘要、亮点
- **四、复盘与优化建议**：共性亮点、存在问题、改进方向
- **五、下一步计划**：持续优化流程、丰富内容、扩大宣传、完善档案
